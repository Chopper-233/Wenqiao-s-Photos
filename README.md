# 李文峤 · Photography

**See the world in my eyes.**

李文峤个人摄影主页，采用静态 HTML、CSS、JavaScript。直接通过 GitHub Pages 发布，不需要构建工具。

网站： https://chopper-233.github.io/Wenqiao-s-Photos/

## 自定义照片和文字

在 `config.js` 中调整摄影系列、作品照片、封面照片、个人介绍和邮箱。

当前展示图片来自 Unsplash，为示例照片，并不是李文峤本人作品。建议替换为个人摄影作品后正式传播。在仓库创建 `photos/` 文件夹上传照片，并在 `config.js` 中使用相对地址，如 `photos/photo01.jpg`。

## GitHub Pages

仓库 Settings → Pages → Build and deployment → Deploy from a branch → main → /(root)。
